# Community intelligence review remediation — 20 October 2026

Catbird's community intelligence work is intended to help people choose accounts and feeds, with understandable content preferences. The independent dossier review identified missing delivery sequencing, control definitions, source/moderation obligations, and evaluation designs. This repair implements bounded local corrections and turns all 38 review findings into explicit work packages or dispositions. It does not establish a production-ready recommendation system or a qualified classifier; the next release still requires current moderation/deletion state, client integration, independent human evaluation, and approval for deployment.

Governing documents: [review remediation plan](../../docs/execution-plans/2026-10-20-catbird-intelligence-review-remediation.md), [master plan](../../docs/execution-plans/2026-10-19-catbird-community-intelligence-master-plan.md), [decision register](../../docs/DECISIONS.md), and [protocol/soak contract](../../docs/design-docs/2026-10-20-catbird-intelligence-protocol-and-soak-contract.md).

## Integrated validation

The full Bun suite passed **34 tests / 146 assertions**, and `bun run typecheck` passed. The existing health-scorer test name claims F1 targets; that test is legacy heuristic fixture coverage and is **not** a trained-classifier accuracy measurement. The current serving receipt separately limits its claims to HTTP behavior and real cryptographic signatures using local keys.

The graph/source suite passed **25 tests**, and the operations suite passed **35 tests**: [graph log](review_graph_all_tests_20261020.txt), [operations log](review_ops_all_tests_20261020.txt). These include numerical boundary cases and structural event fixtures; they do not substitute for real source completeness, graph quality, moderation or deletion latency. The separate account-profile/influence suite passed **8 tests**, including CLI execution and no-overwrite checks. Changed root documentation passed 135 local-link existence checks and whitespace validation.

The model suite passed **80 tests with zero skips**; eight notebook code cells parsed, and the metadata-only blind-review CLI emitted all 600 holdout rows with null human labels. All 15 archived revision-2 files retain their hashes. Across the five non-overlapping suites, **182 tests passed**, plus the separate 30-assertion loopback acceptance receipt. No model-quality conclusion follows from that total.

Independent review found and corrected three concrete defects before integration: stale soak probes could be accepted outside the observation window; old equal-revision conflicts could be hidden by a newer winning record; and orphan teacher shards could be assigned new provenance. Existing bytes were preserved. The model evaluator also uses a nonzero exact upper bound for zero observed decision flips on independent-author rows, rather than treating a degenerate bootstrap interval as proof of zero risk. A separate numerical cross-check covered 142 binomial-tail cases. Further corrections bind required targets and sampling to the frozen contract, require precision-review evidence and equal-inclusion sampling for unweighted population claims, enforce the natural panel duration, and prevent optional heat labels from blocking a politicalness-only profile.
